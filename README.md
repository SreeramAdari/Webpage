# Webpage
This repository contains portfolio site 
Single-page Data Science & Portfolio Website (run.html):

Personal portfolio site for Ganeswara Sai Sreeram Adari, highlighting expertise in Data Science, AI, Python, and automation.

Sections: Home, About, Experience (BHEL apprentice, automation projects), Projects (scraping, sentiment analysis, inventory management, IoT, ML models, etc.), Skills (programming/tools/soft skills), Certifications, Blog (insights on AI, ML, automation, tutorials), Education, and Contact (email, LinkedIn, GitHub).

Features: Responsive design, modern gradient UI, sticky navigation, skills grid, blog CRUD functionality (frontend in-memory; supports backend MySQL integration), and interactive modal for adding/viewing blog posts.

Includes sample backend Node.js code for MySQL integration, making the blog persistent and scalable.

Tech Stack: HTML, CSS, JavaScript (vanilla), optional Node.js/MySQL backend.
